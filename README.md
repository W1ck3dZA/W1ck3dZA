## What I do

I work across both sides of telecoms: running the platforms and writing the software that sits on top of them. Day to day that means SIP and media infrastructure, call-flow engines, and the web tooling that makes it manageable for customers and support teams.

- Designing and operating FreeSWITCH, Kamailio and rtpengine based voice platforms
- Building multi-tenant CPaaS services, call-flow engines and ESL integrations
- Developing admin portals, softphones and monitoring tools in TypeScript and Python
- Automating infrastructure and observability for SIP and Teams Direct Routing setups
